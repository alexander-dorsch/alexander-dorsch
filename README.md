### About

I provide first- and second-level IT support for schools in the public sector, covering end-user devices, Windows infrastructure, network access and cloud services.
My focus is on resolving issues sustainably, automating recurring work and keeping every system thoroughly documented.

### Core Responsibilities

| Area | Scope |
|---|---|
| **End-User Support** | First- and second-level support for hardware and software; analysis, prioritisation and resolution of incidents and service requests |
| **Client Management** | Administration of Windows workstations, notebooks, iPads and printers; provisioning, configuration and replacement of devices |
| **Server &amp; Directory Services** | Windows Server, Active Directory, user accounts, groups and permission management |
| **Software Deployment** | Installation and configuration of applications, including automated software distribution |
| **Network &amp; Security** | Network access, DNS troubleshooting, VPN; IT security and data protection in daily operations |
| **Cloud &amp; Collaboration** | Microsoft 365 administration, Nextcloud administration |
| **Operations &amp; Documentation** | Monitoring operational readiness; documenting incidents, solutions, configurations and changes |
| **Projects &amp; Processes** | Contributing to IT projects, improving support processes and coordinating with central IT, schools and service providers |

### Selected Work

- **Secure exam environment:** locked-down Windows clients in Edge kiosk mode with a local submission server, including documentation for administrators and teachers
- **Self-hosted services:** operation of Nextcloud, Passbolt (password management) and ManageEngine ServiceDesk Plus (ticketing)
- **Knowledge base:** structured internal documentation and how-to guides for administrators and end users
